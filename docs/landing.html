BROWSER EDITION · EARLY RELEASE

A private vault in your browser.

Create encrypted notes, search your saved context, review pattern-based redaction suggestions, and export or restore encrypted backups. Vault contents stay in browser storage; no AI service receives them automatically.

This is a standalone early release. It does not yet include native MCP/REST agent access, desktop vault import, payments, or offline restart. Redaction can miss sensitive information: always review before sharing.

MACOS EDITION

The native context server.

The macOS app provides an encrypted local vault, explicit agent approvals, and loopback REST and stdio MCP transports. The historical signed release is v1.2.1; the repository includes newer changes that have not shipped in that binary.

v1.2.1 release notes (repository access required)

Context escrow and watermarking remain experimental. No working payment settlement, guaranteed leak tracking, or regulatory certification is claimed.
